## Build

Static HTML, generated by [Eleventy](https://www.11ty.dev/) from Markdown
files in `src/notes/`. No framework, no client-side router, no build step in
the browser. The published output is files.

Deployment is a GitHub Actions workflow: push to `{{ site.repoBranch }}`,
Eleventy builds, GitHub Pages serves. There is no server to maintain and
nothing to keep running.

## Typography

System serifs — Iowan Old Style, Palatino, Charter, Georgia, in that order of
preference. No webfonts, which means no font loading, no layout shift, no
third-party request, and a page that renders fully on a bad connection.
Interface text and margin notes use the system sans; code uses the system
mono.

The measure is capped at 40rem, around 68 characters. Footnotes are promoted
into the right margin as sidenotes on wide screens and fold out inline on
narrow ones — so a note is readable without a jump to the bottom of the page
and back.

## The background

A live integration of the Lorenz system at σ=10, ρ=28, β=8/3, stepped with
fourth-order Runge–Kutta and drawn to a canvas with depth-shaded trails.
Roughly 180 lines of dependency-free JavaScript. It respects
`prefers-reduced-motion` — under that setting it renders a single still frame
and stops — pauses when the tab is hidden, and can be switched off entirely
with the ❉ control in the header. The colours are read from CSS custom
properties, so it follows the light and dark themes rather than carrying its
own palette.

[The full explanation](/notes/lorenz-attractor/) is a note of its own.

## Machinery

- **Backlinks** are computed at build time by parsing every note's Markdown
  source for internal links, so the *Linked from* section on each note is
  always accurate and never hand-maintained.
- **Wiki links** — `[[slug]]` or `[[slug|display text]]` — are expanded to
  ordinary anchors before Markdown runs.
- **Table of contents** is generated client-side from the headings, and only
  when a note has at least three.
- **Feed** is Atom, and publishes on tending as well as planting.

## Privacy

No analytics, no cookies, no third-party requests of any kind. The only thing
stored in your browser is your theme preference, in `localStorage`, and only
if you change it from the default.
