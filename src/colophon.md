## Build

Static HTML, generated by [Eleventy](https://www.11ty.dev/) from Markdown
files in `src/notes/`. No framework and no client-side router: the
published output is files. A push to the repository builds the site with a
GitHub Actions workflow, and GitHub Pages serves it. There is no server to
maintain.

## Layout

Three columns, after the manner of [Quartz](https://quartz.jzhao.xyz/):
the Graph View on the left, the page in the middle, the shelves on the
right. Below about 1200 pixels they fold into one column, content first.

- **Graph View** is a small force simulation drawn to a canvas: repulsion
  between every pair of nodes, springs along links, a weak pull to the
  centre. The sidebar shows an entry's immediate neighbourhood; the button
  in its corner opens the whole library. It settles and then stops, so an
  idle graph costs nothing.
- **Backlinks** are computed at build time by parsing every entry's
  Markdown for internal links, so they are never out of date and never
  maintained by hand.
- **Explore** is the entries arranged by the `shelf` in their front matter,
  as plain collapsible lists that work without JavaScript.
- **Search** (press <kbd>/</kbd> or <kbd>Ctrl</kbd> <kbd>K</kbd>) runs in the
  browser over a small index built with the site. Nothing is sent anywhere.

## Typography

[Source Sans 3](https://github.com/adobe-fonts/source-sans) for text and
[Lora](https://github.com/cyrealtype/Lora-Cyrillic) for headings, both
variable fonts under the SIL Open Font License, served from this site
rather than a font CDN. Footnotes become margin notes when the page is wide
enough for them, and fold out inline when it isn't.

## The engraving

The bookshelf across the top of the home page is not a picture. It is SVG
line art generated when the site is built, from a fixed seed: the spines,
their bands and labels, the shading strokes, and the framed plate of the
attractor leaning among them. Book bodies are filled with the page colour
so they hide the hatched wall behind them, which is what makes it read as
an engraving rather than a wireframe.

## The background

A live integration of the Lorenz system at σ=10, ρ=28, β=8/3, stepped with
fourth-order Runge–Kutta and drawn with depth-shaded trails. It respects
`prefers-reduced-motion` (one still frame, no animation), pauses when the
tab is hidden, stops itself if it ever starts costing frames, and can be
paused with the *Attractor* switch in the bottom corner.
[The full explanation](/notes/lorenz-attractor/) is an entry of its own.

## Privacy

No analytics, no cookies, no third-party requests. The only thing stored in
your browser is your theme choice, and only if you change it.
